# DoAnOOP

Đồ án môn Lập trình hướng đối tượng (OOP).

## Giới thiệu

Repository này chứa mã nguồn và các tài liệu phục vụ đồ án OOP.

## Công nghệ

- C#
- .NET
- Lập trình hướng đối tượng
- Git / GitHub

## Kiến thức OOP

Dự án áp dụng các nguyên lý lập trình hướng đối tượng:

- Class và Object
- Encapsulation (Đóng gói)
- Inheritance (Kế thừa)
- Polymorphism (Đa hình)
- Abstraction (Trừu tượng)

## Cấu trúc dự án

Cấu trúc thư mục được tổ chức theo mã nguồn thực tế của project và có thể được cập nhật trong quá trình phát triển.

## Cài đặt

Clone repository:

```bash
git clone https://github.com/khoideptrai1410-wq/DoAnOOP.git
cd DoAnOOP
```

Mở project bằng Visual Studio hoặc môi trường phát triển phù hợp với .NET/C#.

## Chạy chương trình

Build project và chạy ứng dụng bằng Visual Studio hoặc sử dụng .NET CLI nếu project hỗ trợ:

```bash
dotnet build
dotnet run
```

## Mục tiêu

Xây dựng ứng dụng áp dụng các kiến thức OOP, tổ chức mã nguồn rõ ràng và thực hành quy trình quản lý mã nguồn bằng Git/GitHub.
